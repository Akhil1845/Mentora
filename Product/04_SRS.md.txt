# 1. Introduction

Mentora is an AI-powered coding learning platform designed to help students learn programming through guided learning, coding practice, code execution, intelligent post-submission evaluation, visualization, and adaptive learning.

The system combines an AI Coding Mentor with a secure coding environment and learning management components.

Mentora is designed to help students develop programming skills rather than simply generate solutions for them.

---

# 2. Purpose

The purpose of this system is to provide students with an interactive environment where they can:

- Learn programming concepts.
- Understand algorithms and data structures.
- Visualize code and algorithms.
- Practice coding problems.
- Write and execute code.
- Submit coding solutions.
- Receive compiler and execution results.
- Receive AI-powered explanations after submission.
- Track their learning progress.
- Improve through repeated practice.

The system should encourage independent problem solving.

---

# 3. Scope

## 3.1 In Scope

The initial system includes:

- User authentication
- Student profile
- AI Coding Mentor
- Programming lessons
- Coding tasks
- Code editor
- Compiler
- Code execution
- Test-case execution
- Code submission
- Submission history
- AI post-submission evaluation
- Error explanation
- Basic visualization
- Progress tracking
- Skill tracking
- Learning recommendations

---

## 3.2 Out of Scope for Initial Version

The following are planned for future versions:

- Mobile application
- AI-generated full-length videos
- Large-scale competitive programming contests
- Institution management
- Faculty dashboard
- Advanced interview simulation
- Enterprise deployment
- Voice-based coding mentor
- Offline coding environment
