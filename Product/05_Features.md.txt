# 1. Feature Overview

Mentora is built around a simple learning philosophy:

> The student thinks first. Mentora evaluates second.

The platform combines AI mentorship, coding practice, code execution, automated evaluation, visualization, and personalized learning.

The main feature flow is:

```text
Learn
  ↓
Understand
  ↓
Visualize
  ↓
Practice
  ↓
Write Code
  ↓
Run
  ↓
Submit
  ↓
Evaluate
  ↓
Understand Mistake
  ↓
Improve
  ↓
Master
